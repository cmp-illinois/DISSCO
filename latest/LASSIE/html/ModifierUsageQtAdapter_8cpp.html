Validates a LASSIE modifier list and, for small lists, calculates each exact marginal ON rate. Exact preview is deliberately bounded because arbitrary conditional rules require exponential enumeration; synthesis never does.

Runtime sampling stays in the shared, Qt-free ModifierUsage module. This adapter is deliberately narrow so the editor preview cannot acquire its own subtly different probability semantics.
