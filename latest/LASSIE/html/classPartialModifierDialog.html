Detailed Description

Structured editor for any Bottom modifier applied by PARTIAL.

CMOD's legacy format stores four adjacent <Envelope> elements for every partial, in probability/magnitude/width/rate order. This dialog deliberately keeps that wire format while showing only the parameters consumed by the selected modifier type.
