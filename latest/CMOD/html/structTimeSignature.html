◆ CalculateTupletLimit()

size_t TimeSignature::CalculateTupletLimit ( )
inline

Calculate the greatest tuplet type possible in the score, exclusive, and store the duration of one tuplet note of every possible type in valid_dividers_ (from the whole beat down to one EDU). A tuplet type is possible when it divides the beat into equal whole numbers of EDUs, so every divisor of beat_edus_ is one, and the greatest is beat_edus_ itself (one EDU per note). E.g. with 10 EDUs per beat the types are 1, 2, 5 and 10, and CalculateTupletLimit() will return 11.

Returns
the greatest tuplet type possible in the score, exclusive.
