◆ compile()

CompileResult dissco::modifier_usage::compile ( Config  config,
CompileOptions  options = {} 
)

Validate and compile a modifier-usage configuration.

Invalid configurations return diagnostics and no Program. Rule order has no semantic effect: the most-specific matching rule wins. Two rules of equal specificity that can match the same history are rejected as ambiguous.

Exact overall-usage calculation is exponential in the number of modifiers in the worst case, as required for arbitrary dependencies on earlier decisions. Runtime callers should select OverallUsageMode::Skip.
