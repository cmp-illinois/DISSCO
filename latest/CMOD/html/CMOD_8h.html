Detailed Description

Umbrella header for the Composition Module (CMOD).

CMOD is the engine half of DISSCO: it reads a .dissco project file, expands its hierarchical Event tree (top → high → mid → low → bottom), and emits both rendered sound (via the LASS audio library) and a notated score. This header pulls in everything a translation unit outside CMOD needs in order to drive a Piece end-to-end.

Event for the layer base class
Bottom for the leaf event that produces Notes and Sounds
