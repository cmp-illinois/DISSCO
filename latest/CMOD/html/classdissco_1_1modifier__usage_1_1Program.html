Detailed Description

A validated modifier-usage program.

The program is movable but deliberately not copyable because PerBottom sampling owns a cached selection for one runtime Bottom instance.

◆ select() [1/2]

Selection dissco::modifier_usage::Program::select ( const UnitRandom & nextUnit)

Select modifiers with one uniform random value in [0, 1).

Non-empty PerSound programs call nextUnit once per invocation. Non-empty PerBottom programs call it only for the first invocation and return that cached selection thereafter. Empty programs draw nothing. A missing callback or a non-finite/out-of-range result throws std::invalid_argument or std::domain_error respectively.

Selection dissco::modifier_usage::Program::select ( const UnitRandom & nextUnit,
const std::vector< double > & defaultOnChances )

Same as select(nextUnit), but uses defaultOnChances (one per modifier, in configured order) instead of each modifier's compiled Default ON chance. Exceptions still take precedence. This supports Default ON values that change over time. A size mismatch throws std::invalid_argument; a chance outside [0, 1] throws std::domain_error.

CompileResult compile ( Config config,

Validate and compile a modifier-usage configuration.

Invalid configurations return diagnostics and no Program. Rule order has no semantic effect: the most-specific matching rule wins. Two rules of equal specificity that can match the same history are rejected as ambiguous.

Exact overall-usage calculation is exponential in the number of modifiers in the worst case, as required for arbitrary dependencies on earlier decisions. Runtime callers should select OverallUsageMode::Skip.
